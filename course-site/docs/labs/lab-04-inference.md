# Lab 4 — Inference and Truth Maintenance

## Goal

Build a multi-rule classification where derived conclusions change when supporting evidence changes.

**Expected effort:** 90–150 minutes.

## Tasks

1. Model a case with primary evidence and a derived risk marker.
2. Create at least two rules forming a clear inference chain.
3. Demonstrate removal/change of supporting evidence.
4. Prevent accidental execution loops.
5. Test initial, derived, changed and stable states.

## Acceptance criteria

- [ ] Inference chain is explainable.
- [ ] No reliance on source-file ordering.
- [ ] Termination is tested.
- [ ] Derived state follows declared support semantics.

## Required evidence

Source commit, interaction tests, activation/diagnostic evidence where useful, and reflection.

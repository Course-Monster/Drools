# Lab 5 — Model a Decision Service

## Goal

Represent eligibility/risk logic in a decision table or DMN and test boundaries.

**Expected effort:** 90–150 minutes.

## Tasks

1. Define inputs, outputs and decision ownership.
2. Create an eligibility decision plus a risk-band decision.
3. Use explicit boundary values.
4. Add coverage for missing/invalid inputs.
5. Compare the model to an equivalent DRL approach.
6. Record why the selected representation is easier to govern.

## Acceptance criteria

- [ ] Decision dependencies are explicit.
- [ ] 17/18/19 and risk-band boundaries are tested where applicable.
- [ ] No ambiguous overlapping table rows.
- [ ] Outputs have stable names/types.

## Required evidence

Decision model/table, tests, comparison note and source commit.

# Diagnostic Assessment

This is ungraded. Attempt it before reading the modules.

## Questions

1. Explain the difference between imperative control flow and declarative rules.
2. What is a fact in a rule engine?
3. What does a Maven dependency tree help diagnose?
4. Write a Java unit-test assertion for a boundary condition of 18 years.
5. When would you prefer a stateless execution model?
6. What risk can a cross-product of two large fact groups create?
7. What is a decision table?
8. What is the purpose of DMN?
9. Why should a test for a time window use a controllable clock?
10. Name two reasons not to perform HTTP calls directly in a rule consequence.
11. What information would you record to reproduce a production decision?
12. What does “least data necessary” mean in a decision service?

## Interpretation

- **0–4:** complete prerequisites and modules in sequence.
- **5–8:** normal course path.
- **9–10:** skim familiar explanations but complete all labs.
- **11–12:** discuss recognition/prior-learning options if available; still complete summative evidence required for this course version.

Do not use the diagnostic score as proof of course completion.

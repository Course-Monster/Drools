# Learner Guide

## Study method

Each module follows the same learning cycle: **Orient → Learn → Inspect → Practise → Check → Reflect**.

- **Orient:** review outcomes, prerequisites and estimated effort.
- **Learn:** read the concept sections and inspect the examples.
- **Inspect:** explain the example before running it.
- **Practise:** complete the linked lab without using the solution key.
- **Check:** complete the module knowledge check.
- **Reflect:** write a short note describing what changed in your mental model.

Plan focused sessions of 45–90 minutes. For a technical self-paced course, small repeated sessions usually produce better retention than a single long session.

## Prerequisite knowledge

You should be able to read/write basic Java, use Maven from a terminal, understand unit-test assertions, work with Git branches/commits, distinguish source/config/build/runtime artifacts, and understand basic HTTP/service concepts.

## Getting help

When blocked, record the intended outcome, exact command/test, complete error, Java/Maven/Drools versions, smallest reproducible rule/model, and what you already tried. Use the troubleshooting guide before escalating and never post credentials, tokens, customer data or assessment answers.

## Assessment integrity

Formative checks are for learning. The final assessment and capstone are evidence of competence. Your submission must be your own explainable work. External references and AI assistance may be used only within the policy set by the publishing learning platform.

## Accessibility and accommodations

The canonical material is text-first and is designed toward WCAG 2.2 AA. Learners who require an alternative format, additional time, keyboard-only interaction, captions/transcripts or another reasonable accommodation should use the Academy accessibility/support process configured with the published course. If a diagram conveys information, surrounding text must convey the same essential information. Do not rely on colour alone.

## Privacy and safe lab data

All labs use synthetic data. Never copy real personal, health, financial or customer records into a course repository. Do not commit secrets. If a secret is exposed, revoke it; deleting the latest file is not sufficient.

## Version policy

The canonical technical baseline is shown on Start Here. Course maintainers should compare examples with referenced Apache KIE documentation, review the baseline at least every six months and review immediately after a major Drools release.

## Assessment model

- **Diagnostic:** ungraded; identifies prior knowledge.
- **Module checks:** formative; target 80%; repeat after remediation.
- **Labs:** evidence-based practice; self-check against acceptance criteria.
- **Final assessment:** summative knowledge/application check; pass mark 75%.
- **Capstone:** summative performance assessment; pass mark 70% plus critical criteria.

## Suggested pacing

A four-week plan uses two modules per week plus the capstone. An eight-week plan uses one module per week, then capstone and remediation. Completion is based on demonstrated outcomes, not time spent.

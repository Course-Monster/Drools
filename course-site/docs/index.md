# Drools Decision Automation

Build practical competence in rule-driven decision automation with **Drools 10.2** through structured modules, executable labs, formative mastery checks and an end-to-end capstone.

## Course at a glance

- 8 technical modules
- 8 hands-on labs
- 32–40 nominal learning hours
- diagnostic and summative assessment
- capstone performance assessment
- learner notes, glossary, cheat sheet and troubleshooting guide
- standards-aligned quality and accessibility controls
- versioned technical baseline and publishing evidence

## Begin

Go to **[Start Here](./start-here)** for outcomes, completion rules and the learning contract.

Then complete the **[Diagnostic Assessment](./assessment/diagnostic)** and **[Environment Setup](./environment-setup)**.

## Technical baseline

The learning content is modernized from the repository's original Drools 8 instructor-led course and targets the current Apache KIE/Drools 10.2 documentation family. Legacy PDFs and course source assets are preserved outside this canonical learner site.

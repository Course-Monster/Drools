# Drools Decision Automation — Self-Paced

<div className="course-meta">

**Technical baseline:** Drools / Apache KIE 10.2.0  
**Delivery:** asynchronous, self-paced, lab-driven  
**Nominal effort:** 32–40 hours  
**Recommended pacing:** 4–8 weeks  
**Difficulty:** intermediate  
**Language:** English  
**Version:** 1.0.0

</div>

This course develops the ability to design, implement, test, explain and operate business decision automation with Drools. It replaces the repository's legacy three-day, Drools 8 instructor-led structure with a mastery-oriented path designed for independent learners.

## What you will be able to do

On successful completion you will be able to:

1. **Explain** the role of rules, facts, working memory, production memory and the agenda in the Drools engine.
2. **Implement** maintainable DRL rules using appropriate constraints, bindings and consequences.
3. **Select and configure** stateful, stateless and Rule Unit-oriented execution approaches for a stated use case.
4. **Control and explain** rule execution using inference, truth maintenance, agenda concepts and rule attributes.
5. **Model decisions** with decision tables and DMN, and justify when each representation is appropriate.
6. **Implement** event-driven rules using event processing, temporal reasoning and windows.
7. **Verify and troubleshoot** rule behaviour with automated tests, logging, diagnostics and performance evidence.
8. **Integrate and operate** Drools safely in a service-oriented application with versioning, observability and change controls.
9. **Deliver** a capstone decision service whose requirements, rules, tests and operational decisions are traceable.

## Completion standard

To earn course completion status, a learner should:

- complete all eight modules and eight labs;
- score **80% or higher** on each module knowledge check after remediation;
- score **75% or higher** on the final assessment;
- achieve **70% or higher** on the capstone rubric, with no critical criterion marked “Not demonstrated”;
- submit the learner evidence described in each lab;
- complete the end-of-course evaluation.

The Docusaurus site itself does not issue credentials. Completion tracking, identity verification, retakes and certificates must be enforced by the LMS or Academy platform used to publish this content.

## Evidence you should retain

Keep a learning portfolio containing lab repositories or commit SHAs, test output, design notes and decision records, knowledge-check remediation notes, capstone requirements-to-test traceability, and a final reflection.

## Learning contract

You may use official documentation and your own notes during labs. Do not copy model answers or assessment keys. Treat code generated by AI tools as untrusted input: review it, explain it, test it and cite assistance according to the Academy's assessment policy.

# Quality Evidence Register

This register identifies evidence expected for each published course version.

| Evidence | Owner | Location | Frequency |
|---|---|---|---|
| Course design specification | Course owner | `governance/COURSE_DESIGN_SPEC.md` | version change |
| Outcome/assessment matrix | Instructional designer | `governance/OUTCOME_ASSESSMENT_MATRIX.md` | material design change |
| Technical SME review | SME | PR review / issue | each release |
| Accessibility review | QA/accessibility reviewer | release issue/artifact | each release |
| Build/content validation | CI | GitHub Actions | every PR |
| Changelog | Course owner | `course-site/CHANGELOG.md` | each release |
| Learner evaluation summary | Course owner | learning platform | per cohort/quarter |
| Corrective actions | Course owner | GitHub issues / QMS | as required |
| Assessment calibration | Lead assessor | controlled record | each assessment version |

Do not store sensitive learner records in this public repository.

# Course Design Specification

## Identity

- Title: Drools Decision Automation — Self-Paced
- Provider: Skunkworks Academy
- Course version: 1.0.0
- Technical baseline: Drools 10.2.0
- Delivery: asynchronous online
- Nominal learning effort: 32–40 hours
- Target level: intermediate
- Review cycle: six-month technical review; annual full design review

## Target audience

Java developers, solution architects, technical business analysts, integration engineers and decision-automation practitioners.

## Learning strategy

Outcome-first alignment: every module contains measurable outcomes, concise concept material, a practical lab, mastery check and reflection. The capstone integrates technical and operational competence.

## Assessment strategy

Diagnostic → formative checks → labs → final assessment → capstone. Mastery thresholds are published. Controlled marking material remains outside learner-facing Docusaurus docs.

## Learning environment

Text-first Docusaurus site plus a Java/Maven lab environment. The host Academy/LMS supplies authenticated learner identity, progress tracking, submissions, retakes, feedback and credentials.

## Data classification

Course examples use synthetic/public technical data only. Course repositories must not solicit real health, financial or customer data.

## Change control

Material changes require: issue/change rationale; SME review; instructional/assessment impact check; accessibility impact check; build/validation; version/changelog update; release approval.

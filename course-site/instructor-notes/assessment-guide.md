# Controlled Assessment and Assessor Guide

> This directory is intentionally outside the Docusaurus `docs/` tree. Do not copy controlled answers into public learner pages.

## Purpose

Maintain consistent marking, remediation and evidence practices.

## Assessment principles

- Assess stated outcomes only.
- Use the published rubric and blueprint.
- Require executable/inspectable evidence for technical claims.
- Do not award marks for unexplained complexity.
- Accept alternate correct implementations when they satisfy requirements and are explainable.
- Record the reason for any critical fail.
- Use a different item set for a retake where the platform supports an item bank.

## Capstone calibration questions

1. What constitutes sufficient automated testing?
2. Which security failures are critical?
3. How much trace metadata is sufficient without unnecessary input collection?
4. What evidence proves session-lifecycle understanding?
5. What decision-model complexity is appropriate for the course level?

## Suggested oral verification

- Explain one rule line-by-line.
- Change a boundary and predict failing tests.
- Explain why the chosen session type fits.
- Identify one production risk.
- Show the exact commit assessed.

Do not use oral verification to introduce new unstated requirements.

## Remediation

Map missed evidence to outcomes, specify the minimum corrective activity, and allow reassessment according to controlled Academy policy.

# Lab Solutions Outline — Controlled

This file deliberately provides **solution criteria rather than copy-ready complete solutions** so assessors can validate alternate learner implementations.

## Lab 1

Expect a clean Maven project, pinned Drools baseline, three intent-revealing rules and boundary tests.

## Lab 2

Expect constrained joins using shared identifiers, explicit manual-review policy, no real sensitive data, and evidence overlap was considered.

## Lab 3

Expect a defensible stateless choice for independent decisions and explicit lifecycle handling for stateful work.

## Lab 4

Expect a testable inference chain and termination safeguards. The learner must explain support/retraction behaviour.

## Lab 5

Expect visible decision dependencies, boundary tests and rationale for DRL/table/DMN representation.

## Lab 6

Expect controlled time, bounded windows and documented duplicate/replay assumptions.

## Lab 7

Evidence should show failing test → diagnosis → minimal fix → regression pass.

## Lab 8

Expect validation outside the engine, version metadata, no embedded secrets, external side effects outside consequences, and rollback guidance.

# Slide Source

These Markdown files are editable slide-source outlines suitable for rendering with Marp or adapting into the Academy slide system.

Slides are **learning aids**, not the canonical source of technical detail. The Docusaurus module pages and executable labs are canonical.

Accessibility requirements for rendered decks:

- preserve reading order;
- use adequate contrast and large text;
- provide alt text for informative images;
- do not communicate meaning by colour alone;
- provide speaker notes/transcript-equivalent text for narrated recordings;
- ensure exported PDFs are tagged and manually checked if PDF becomes a required learner format.
